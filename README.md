# Algorithms

*Познаю алгоритмический мир программирования. На ноябрь 2026 на языке C#.*

**Желаю себе же успехов!)**

В репозитории: 
- Папка LeetCode с решениями задач LeetCode. Файлы создаются в формате: номер задачи, название задачи.
- Папка NeetCode с решениями задач NeetCode, отсортированная по главам Roadmap'a. Файлы создаются в формате: название задачи.
- Папка TContext с задачами с Т-Контекста (при их наличии).
- Папка debug_project -> AlgoProj с консольным приложением для решения алгоритмических задач и их отладки.

Файлы решения задач в случае дублирования их на ресурсах LeetCode и NeetCode дублируются в обе папки согласно форматам названия соответствующих.
